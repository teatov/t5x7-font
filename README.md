A little monospaced pixel font I made. Glyphs are 5 by 7 pixels,
with ascent of 3 and descent of 2, so the total height is 12.

Implements the entire [Windows Glyph List 4](https://en.wikipedia.org/wiki/Windows_Glyph_List_4),
which represents the majority of European languages (that use Latin, Greek and Cyrillic) plus extra punctuation, symbols and box drawing.

Made using the brilliant [Pixel Font Converter by YellowAfterlife](https://yellowafterlife.itch.io/pixelfont). Glyphs are drawn in [Krita](https://krita.org/en/).
